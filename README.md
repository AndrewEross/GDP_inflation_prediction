Hello and welcome to our DS340W research paper github. One important thing to mention before you attempt to run the code provided. You must create your own API from FRED API.
Instructions for this are provided in the first cell of the Jupyter notebook. It should take no longer than 2 minutes.

Once you do that and you past the key into the provided area, you can begin running the Jupyter notebook.

Once you have the API key inserted, you can successfully run all code. Be sure to pip install any missing packages if an error regarding those comes up. 

Thank you!
